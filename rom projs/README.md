# Portfolio: Romm Aldred L. Abaya

Personal portfolio built with HTML, CSS and vanilla JavaScript.

## Projects in this repository
| Project | Category | Folder |
|---|---|---|
| Password Strength Checker | Cyber security | `projects/password-checker` |
| Small Business Website | Simple website | `projects/business-website` |
| Student Records System (PHP + MySQL) | Database | `projects/student-records` |

## Connect the site to this repository
Open `script.js` and set `GITHUB = { user, repo, branch }` (near the middle of the file). The "Source Code" buttons and GitHub links then point here.

## Deploy
- **GitHub Pages:** Settings > Pages > deploy from the `main` branch. (PHP does not run on GitHub Pages.)
- **InfinityFree:** upload everything into `htdocs`. The PHP contact API and the Student Records app work there.
